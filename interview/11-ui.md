# 11 · ui 模块学习要点

> 基于 `src/com/interface21/ui/**`（8 个 `.java`，无专属测试）逐字核对编写。
> ui 模块很小，核心是"主题（Theme）抽象"，为 [web](12-web.md) 的主题能力提供契约。

## 模块定位

ui 模块定义**主题（Theme）的抽象层**，使 web 层的主题解析（`ThemeResolver`）与主题内容（CSS、图片路径、文案等）解耦。它**不依赖 Web 容器**，可被任何 ApplicationContext 使用——web 模块通过让 `WebApplicationContext extends ThemeSource` 来接入。

> 这是 web 与 ui 两个模块的**真正耦合点**：`WebApplicationContext extends ApplicationContext, ThemeSource`；而 `XmlWebApplicationContext extends AbstractXmlUiApplicationContext`（本模块 `ui.context.support`），后者在 `onRefresh()` 用 `UiApplicationContextUtils.initThemeSource` 装配 `ThemeSource`（默认 `ResourceBundleThemeSource`）。

## 子包结构

```
ui/context/           契约：Theme / ThemeSource / NestingThemeSource
ui/context/support/   实现：AbstractXmlUiApplicationContext / StaticUiApplicationContext
                       ResourceBundleThemeSource / SimpleTheme / UiApplicationContextUtils
```

## 核心接口（逐字签名）

### `Theme` — `ui/context/Theme.java`
```java
String getName();
MessageSource getMessageSource();
```
职责：主题 = 名字 + 专属于该主题的 `MessageSource`（CSS、图片路径、文案等）。主题内容复用 [context](04-context.md) 的 `MessageSource` 机制，因此天然支持 i18n。

### `ThemeSource` — `ui/context/ThemeSource.java`
```java
Theme getTheme(String themeName);
```
职责：按主题名取 `Theme` 实例。

### `NestingThemeSource extends ThemeSource` — `ui/context/NestingThemeSource.java`
```java
void setParent(ThemeSource parent);
```
职责：可分层主题源——本节点解析失败时委派 parent（与 `NestingMessageSource` 同构）。

## 核心实现类（support 子包）

| 类 | 要点 |
|----|------|
| `ResourceBundleThemeSource` | 基于 JDK `ResourceBundle`，每个主题一个 basename（约定 `themename.properties` 等）；按 themeName 缓存 `Theme` |
| `SimpleTheme` | `Theme` 的简单实现，包名字 + 一个 `MessageSource` |
| `AbstractXmlUiApplicationContext` | 在 XML 应用上下文基础上，`onRefresh()` 调 `UiApplicationContextUtils.initThemeSource` 装配 `ThemeSource`（取名为 `themeSource` 的 bean，无则默认 `ResourceBundleThemeSource`） |
| `StaticUiApplicationContext` | 编程式注册的 UI 上下文（测试用） |
| `UiApplicationContextUtils` | 静态工具：`initThemeSource(ApplicationContext)` —— 在上下文中查找/创建 `ThemeSource` 并注入 |

## 关键设计模式

| 模式 | 类 |
|------|----|
| 策略 | `ThemeSource`（可换实现：`ResourceBundleThemeSource` 等） |
| 分层/委派 | `NestingThemeSource.setParent`，与 `NestingMessageSource` 同构 |
| 组合 | `Theme` 组合一个 `MessageSource`，复用 i18n 基础设施 |
| 模板方法 | `AbstractXmlUiApplicationContext.onRefresh()` 钩子装配 ThemeSource |

## 对应测试

ui 模块**无专属测试**。主题能力在 web 测试（`ThemeResolverTestSuite`）与 context 测试中顺带覆盖。

## 建议学习顺序

1. `Theme` / `ThemeSource` / `NestingThemeSource`（三个契约接口）
2. `ResourceBundleThemeSource` + `SimpleTheme`（默认实现）
3. `UiApplicationContextUtils.initThemeSource`（ThemeSource 如何被装配进上下文）
4. 结合 [web](12-web.md) 的 `ThemeResolver` / `ThemeChangeInterceptor` 看完整主题链路：`ThemeResolver` 只决定主题**名字**，`ThemeSource` 按名字取 `Theme`，`Theme` 内的 `MessageSource` 提供内容

## 值得精读的源码片段

| 片段 | 为什么 |
|------|--------|
| `ui/context/Theme.java` | 理解"主题 = 名字 + MessageSource"的极简建模 |
| `ui/context/support/ResourceBundleThemeSource.java` | 按 themeName 缓存 Theme、基于 ResourceBundle 加载主题资源 |
| `ui/context/support/UiApplicationContextUtils.java:initThemeSource` | ThemeSource 装配进 ApplicationContext 的入口 |
| `web/context/WebApplicationContext.java` | `extends ApplicationContext, ThemeSource`——web 与 ui 的耦合点 |

---

**一句话总结**：ui 模块用 `Theme`（名字 + MessageSource）/ `ThemeSource`（按名取主题）/ `NestingThemeSource`（分层）三件套抽象"主题"，复用 context 的 i18n 基础设施；web 通过 `WebApplicationContext extends ThemeSource` 接入，`ThemeResolver` 只决定名字、`ThemeSource` 提供内容。
